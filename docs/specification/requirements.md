# Специфікація вимог до програмного забезпечення (SRS)
**Проєкт:** CineVerse (Онлайн-кінотеатр)

## 1. Межі проєкту та призначення
CineVerse — це вебсервіс для кінотеатрів, який дозволяє користувачам переглядати каталог фільмів, вибирати сеанси, бронювати місця через інтерактивну карту зали в реальному часі, здійснювати оплату та отримувати електронні квитки з QR-кодом.

## 2. Функціональні вимоги
* **Керування каталогом:** Адміністратори можуть створювати, редагувати та видаляти інформацію про фільми, жанри, кінотеатри та зали.
* **Сеанси та бронювання:** Користувачі можуть переглядати розклад сеансів, вибирати вільні місця на інтерактивній схемі (`SeatMap`) та створювати бронювання.
* **Система оплати:** Підтримка імітації платіжних шлюзів, обробка вебхуків (Webhooks) та підтвердження готівкових платежів.
* **Валідація квитків:** Контролери на вході до залу можуть сканувати QR-коди квитків через спеціальний інтерфейс (`CheckerPage`) для їх перевірки.
* **Аналітика:** Адмін-панель містить звіти щодо заповнюваності сеансів та прибутків за дні.

## 3. Нефункціональні вимоги
* **Продуктивність:** Оновлення статусу вільних/занятих місць через SignalR має відбуватись із мінімальною затримкою.
* **Надійність:** Захист від гонки (race conditions) при паралельному бронюванні однакових місць різними користувачами.
