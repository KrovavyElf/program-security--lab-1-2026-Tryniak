# Опис архітектури системи
**Проєкт:** CineVerse

## 1. Архітектурний патерн
Бекенд застосунку побудований на засадах **Clean Architecture** (Чистої архітектури) з використанням .NET, що забезпечує чіткий розподіл на шари:
* **Domain:** Бізнес-сутності, переліки (Enums), винятки.
* **Application:** Бізнес-логіка, команди та запити (CQRS через MediatR), інтерфейси та валідатори (FluentValidation).
* **Infrastructure:** Реалізація роботи з базами даних (Entity Framework Core, PostgreSQL), сервіси JWT, кешування, генерація QR-кодів.
* **WebApi:** REST API контролери, хаби SignalR, налаштування middleware та конфігурації.

## 2. Кліентська частина (Frontend)
Фронтенд реалізований на **React / Vite** з використанням **Redux Toolkit** для управління станом, **TailwindCSS** для стилізації та бібліотеки маршрутизації.

## 3. База даних
Використовується реляційна база даних **PostgreSQL**. Для початкового заповнення даними (Seed) передбачені міграції та SQL-скрипти у папці `database/init/`.
