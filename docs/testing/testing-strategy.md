# Стратегія тестування
**Проєкт:** CineVerse

Для забезпечення якості та надійності програмного продукту проєкт містить кілька рівнів тестування у каталозі `tests/`:
* **Модульні тести (Unit Tests):** Розташовані у проєкті `CineVerse.UnitTests`. Перевіряють ізольовану бізнес-логіку (валідатори, калькулятори цін на місця, обробники команд).
* **Інтеграційні тести (Integration Tests):** Розташовані у `CineVerse.IntegrationTests`. Тестують взаємодію API-контролерів, роботу з базою даних та сценарії автентифікації.
* **Навантажувальні тести (Load Tests):** Сценарії на кшталт `booking-race-condition.js` (використовують інструменти на кшталт k6) для перевірки стійкості серверу до умов гонки під час масового бронювання квитків.
