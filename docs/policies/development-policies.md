# Політики та правила розробки
**Проєкт:** CineVerse

## 1. Правила роботи з системою контролю версій (Git)
* **Гілкування:** Основною робочою гілкою є `main`. Нові фічі або виправлення розробляються в окремих гілках та інтегруються через Pull Requests.
* **Правила комітів:** Повідомлення комітів мають бути чіткими. Початкові або ініціалізаційні коміти структури проєкту обов'язково починаються з префіксу `[INIT]`.

## 2. Стандарти коду
* Дотримання загальноприйнятих конвенцій для C# (.NET) та TypeScript/React.
* Обов'язкове використання валідації вхідних даних та глобальної обробки винятків (`ExceptionHandlingMiddleware`).
