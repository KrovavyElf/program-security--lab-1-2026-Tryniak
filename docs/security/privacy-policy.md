# Політика конфіденційності CineVerse

## 1. Загальні положення
Ця Політика конфіденційності визначає порядок збору, обробки, зберігання та захисту персональних даних користувачів вебсервісу онлайн-кінотеатру **CineVerse**, відповідно до загальних вимог безпеки даних[cite: 3].

## 2. Категорії даних, що збираються
Відповідно до принципу **мінімізації даних**, система збирає лише ту інформацію, яка необхідна для забезпечення функціональності кінотеатру[cite: 3]:
- **Облікові дані:** Ім'я користувача, адреса електронної пошти (Email), хешований пароль.
- **Дані взаємодії:** Історія бронювання місць, куплені квитки, обрані фільми.
- **Технічні дані:** Логи підключень, файли сесій (JWT).

## 3. Мета обробки даних
- Реєстрація та автентифікація користувачів у системі CineVerse.
- Оброблений процес бронювання білетів та генерація електронних квитків.
- Забезпечення безпеки облікових записів та запобігання шахрайству.

## 4. Захист та зберігання персональних даних
- Усі персональні дані передаються за допомогою захищеного протоколу HTTPS (TLS 1.3).
- Паролі та чутлива інформація шифруються при зберіганні в базі даних PostgreSQL.
- Термін зберігання персональних даних обмежується періодом активного використання акаунта користувачем. У разі видалення акаунта дані підлягають знеособленню або безповоротному видаленню[cite: 3].
