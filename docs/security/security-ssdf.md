# Політика безпечної розробки (NIST SSDF)
**Проєкт:** CineVerse

Відповідно до рамкової моделі **NIST SP 800-218 (SSDF)**, у проєкті реалізовано такі заходи безпеки:
* **Захист облікових даних:** Хешування паролів за допомогою безпечних алгоритмів (`PasswordHasher`), використання токенів доступу (JWT).
* **Контроль доступу:** Ролева модель (Role-Based Access Control) для розмежування прав звичайних користувачів та адміністраторів (`AdminNav`, `RoleRoute`).
* **Безпека даних:** Захист від несанкціонованих змін та валідація вхідних запитів на рівні Application-шару (FluentValidation).
* **Управління секретами:** Чутливі дані (рядки підключення до БД, секретні ключі JWT) винесені у змінні середовища (`.env`), які не потрапляють до публічного репозиторію через `.gitignore`.
